# Third-party components bundled with ARGB Studio

This folder ships unmodified binaries of the following open-source projects.
Their source code can be obtained from the links below.

## OpenRGB

- Role: hardware layer (headless SDK server) that ARGB Studio talks to
- Version: release_1.1 (Windows 64-bit build)
- License: GPL-2.0
- Source: https://codeberg.org/OpenRGB/OpenRGB
- Binary source of this build: https://codeberg.org/OpenRGB/OpenRGB/releases/tag/release_1.1

## Vazirmatn font

- Role: Persian UI font (bundled in app/assets/fonts)
- License: SIL Open Font License 1.1
- Source: https://github.com/rastikerdar/vazirmatn

## Python (embedded runtime)

- Role: runs the application (runtime/python)
- License: Python Software Foundation License (PSF)
- Source: https://www.python.org
